Magic Spotlight is a lightweight portfolio / personal brand website to promote your products, content and newsletter.

It's best suited for founders who want to build a presence online through long-form content. The MDX-based content system allows you to write in Markdown and JSX, giving you the flexibility to create engaging and interactive content.

The blog is SEO-friendly, responsive and supports most Once UI components, and you can always extend it with others.

---

## A smart system to create beautiful content

Our MDX transformer replaces standard markdown elements with Once UI components to apply a consistent look and feel with the rest of the site. You can add images, videos, headings, lists, dividers, quotes, and more.

![Product curve](/images/blog/blog-02.jpg)

**Easy to format content:** The power of markdown<br/>
A simple system that takes care of whitespaces and formatting

**SEO-friendly:** Metadata, image generation and more<br/>
Metadata is generated automatically based on your content with dynamic images

**Responsive:** Focus on content<br/>
Forget about CSS, styling, and fixing UI bugs. Start with a system that just works.
